# DeployFlow — Лендинг с автодеплоем

Статический лендинг для лабораторной работы №6  
**Автоматизация развёртывания проекта с помощью GitHub Actions (CI/CD)**

## Как запустить

1. Создайте репозиторий на GitHub
2. Загрузите все файлы из этой папки
3. Перейдите в **Settings → Pages**
4. В разделе **Build and deployment** выберите источник **GitHub Actions**
5. Сделайте любой commit/push — сайт опубликуется автоматически

## Структура

- `index.html` — главная страница лендинга
- `style.css` — стили
- `.github/workflows/deploy.yml` — workflow автодеплоя
